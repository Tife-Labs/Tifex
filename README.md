## 🚀 Getting Started

### Prerequisites

- **Node.js 20 LTS** or newer — check with `node -v`
- **npm** (bundled with Node)

### Install & run locally

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/tifex-by-tifelabz.git
cd tifex-by-tifelabz

# 2. Install dependencies
npm install

# 3. Create your local env file from the template
cp .env.example .env.local

# 4. Open .env.local and fill in the real values
#    (see "Environment Variables" section below)

# 5. Start the dev server
npm run dev
